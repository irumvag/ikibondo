# Translations plan (Kinyarwanda, French)

_Status 2026-11-26: the web app is wired for translations and the public website's text is in
`frontend/messages/en.json` (step 1 below, public pages done). Everything still shows in English: `rw.json`
and `fr.json` are empty until a translator fills them._

## Where things stand

| Surface | Today | Language source |
|---|---|---|
| Web (Next.js) | Public website: text in `messages/en.json` through `next-intl`. Signed-in pages: English, inline in components. | `ikibondo_locale` cookie, set from `preferred_language`; signed out: the browser's language |
| Mobile (Flutter) | All text is English, inline in widgets. | — |
| Backend emails | `templates/emails/<name>/{en,fr,rw}.{html,txt}` for most emails. `password_reset` and `account_setup` are English only (the sender falls back to English). | `user.preferred_language` (`en` / `fr` / `rw`) |
| Backend SMS | English text in code (`password_reset.py`, `account_setup.py`, vaccination reminders). | — |

The existing `rw` and `fr` email templates have not been reviewed by a native speaker; treat them as drafts.

## Ground rules

- **No machine translation of health guidance.** MUAC bands, referral instructions and vaccine reminders
  change what a parent or CHW does. A native Kinyarwanda speaker with health-worker experience writes or
  approves every string.
- **A glossary comes first**: MUAC, SAM/MAM, oedema, referral, dose, growth chart, risk levels, and the
  names of roles (CHW, nurse, supervisor). The same term is used everywhere.
- **English is the fallback** for any string not yet translated, so partial translations are safe to ship.
- The language shown follows `preferred_language` on the account; signed-out pages follow the browser/phone.

## Steps (when the translator is ready)

1. **Extract English into catalogs.** No visible change to users.
   - Web: `frontend/messages/en.json`, loaded through `next-intl`; start with the CHW and parent screens.
   - Mobile: `mobile/lib/l10n/app_en.arb` with Flutter `gen-l10n` (`flutter_localizations`); Material
     widgets need a fallback delegate for `rw`, which Flutter does not ship.
   - Backend: move SMS texts into the same template folders (`sms.txt` next to each email).
2. **Hand the translator one file per surface** (`en.json`, `app_en.arb`, email/SMS templates) plus the
   glossary. They return `rw.json`, `app_rw.arb` and `rw.*` templates; nothing else needs code changes.
3. **Review in the field** with two or three CHWs and parents, on the actual screens.
4. **Turn on the language switch** in profile settings (the field already exists on the account).

## Web: how it works

- `src/i18n/request.ts` picks the language for each request and loads `messages/<lang>.json` merged over
  English, so every missing string falls back to English. A language with an empty file renders as English
  (and `<html lang="en">`), so nothing changes until real translations arrive.
- `LocaleSync` (root layout) writes the `ikibondo_locale` cookie whenever the account's `preferred_language`
  changes, from the top-bar switcher or the profile page.
- In components: `const t = useTranslations('nav')` then `t('home')` (client and server components), or
  `await getTranslations('meta')` in `generateMetadata`. Values go in placeholders (`'Visit at month {month}'`);
  bold text or links inside a sentence use `t.rich` with tags (`'Remembered it? <link>Sign in</link>'`), so a
  translator can reorder them.
- Keys are type-checked against `en.json` (`src/i18n/global.d.ts`): a typo fails `npx tsc`.
  `src/i18n/i18n.test.ts` fails if `rw.json` or `fr.json` has a key that `en.json` doesn't.
- Form schemas use keys under `validation` as their error messages; show them with `useValidationMessage()`.
- Admin-editable site content (Admin → Site content) and FAQ answers are already stored per language; the
  public pages now ask for the visitor's language.

## Effort estimate

Extraction is mechanical but touches most screens: roughly 2–3 days for web, 2 days for mobile, half a day
for backend messages. Step 1 produces the exact string counts, which set the translation effort.
